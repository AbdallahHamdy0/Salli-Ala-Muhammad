# صلِّ على محمد ﷺ

تطبيق أندرويد (Flutter) بيفكّرك بالصلاة على النبي ﷺ كل فترة تختارها، ومعاه أذكار الصباح والمساء وأذكار عشوائية على مدار اليوم.

> اللهم صلِّ وسلم على نبينا محمد

## التحميل

**[⬇️ تحميل التطبيق (APK)](https://github.com/AbdallahHamdy0/Salli-Ala-Muhammad/releases/download/v1.0.0/salli-ala-muhammad.apk)** — أو من صفحة [Releases](https://github.com/AbdallahHamdy0/Salli-Ala-Muhammad/releases).

التثبيت: نزّل الملف من الموبايل ← اسمح بالتثبيت من هذا المصدر ← لو ظهر تحذير Play Protect اختار «التثبيت على أي حال» (طبيعي لأي تطبيق مش من المتجر). عند أول فتح هيطلب الإشعارات والمنبهات الدقيقة واستثناء البطارية، وافق على الكل علشان التذكير يشتغل في ميعاده.

## المميزات
- **تذكير صوتي** كل 5 / 10 / 15 (الافتراضي) / 30 دقيقة / ساعة / ساعتين / 3 ساعات، بصوت يتخطى الوضع الصامت و«عدم الإزعاج» (ما عدا «الصمت التام»).
- **التفعيل عند فتح الشاشة** وعند الوضع الصامت (مفتاحين مستقلين).
- **أذكار الصباح والمساء** (31 و30 ذكر بأعداد التكرار): تنبيه الصباح 7:30 ص والمساء 7:00 م + تذكير بعد 30 دقيقة لو ما فتحتش. لكل ذكر **عدّاد** وسهم إعادة، والتقدّم بيتحفظ لنفس اليوم.
- **أذكار عشوائية** على مدار اليوم (إشعار كل نصف ساعة، والضغط عليه يفتح كارت).
- **صدقة جارية**: صفحة أدعية للقراءة والمشاركة.
- كل التنبيهات **مفعّلة افتراضياً** عند أول تشغيل.

## الخصوصية والصلاحيات
- **مفيش إنترنت**: التطبيق ما بيتصلش بأي سيرفر ومفيش تحليلات ولا إعلانات ولا مكتبات خارجية.
- مفيش وصول للموقع أو جهات الاتصال أو الكاميرا أو الميكروفون أو التخزين. البيانات الوحيدة المخزّنة هي إعداداتك على الموبايل نفسه.

| الصلاحية | ليه |
|---|---|
| `POST_NOTIFICATIONS` | إشعارات الأذكار (أندرويد 13+) |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | تشغيل التنبيه في ميعاده بالظبط |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | خدمة صغيرة بتسمع لفتح الشاشة (أندرويد بيشترطها) |
| `RECEIVE_BOOT_COMPLETED` | رجوع التنبيهات بعد إعادة تشغيل الموبايل |
| `WAKE_LOCK` | إبقاء الموبايل صاحي لحد ما الصوت يخلص (ثواني) |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | نافذة «استثناء من توفير البطارية» (مرة واحدة) |

## البناء من الكود
المطلوب: **Flutter 3.27 أو أحدث** + Android SDK (`flutter doctor` من غير أخطاء) + إنترنت لأول بناء + **ملف صوتك** (`mp3` / `wav` / `ogg` / `m4a`، أقل من 8 ثواني).

> ملف الصوت **مش موجود في المستودع** (هو بتاع صاحب التطبيق). لازم تحط ملفك أنت.

```bash
# Mac / Linux / Git Bash
./build_apk.sh /مسار/صوتك.mp3
```
```powershell
# Windows PowerShell  (لو التشغيل متمنوع: Set-ExecutionPolicy -Scope Process Bypass)
.\build_apk.ps1 -Sound "C:\مسار\صوتك.mp3"
```
السكريبت بيعمل مشروع Flutter جديد، وينسخ `salli_app/` فيه، ويحط صوتك، ويضبط `minSdk = 26`، ويبني `salli-ala-muhammad.apk` جنب السكريبت.

## التعديل
| الحاجة | الملف |
|---|---|
| الفترة الافتراضية للتذكير (15) | `salli_app/lib/constants.dart` ← `kDefaultIntervalMinutes` |
| مواعيد أذكار الصباح والمساء والتذكير | `kMorningHour/Minute`، `kEveningHour/Minute`، `kDailyFollowUpMinutes` (0 = بدون) |
| فترة الأذكار العشوائية | `kAdhkarIntervalMinutes` |
| رابط المشاركة | `kAppLink` |
| أدعية «صدقة جارية» | `salli_app/lib/data/duas.dart` |
| الأذكار العشوائية | `salli_app/lib/data/adhkar.dart` |
| أذكار الصباح والمساء | `salli_app/lib/data/azkar_daily.dart` |

ملحوظة: ميعاد المغرب بيتغيّر طول السنة (في الشتا حوالي 5 العصر)، فعدّل `kEveningHour` لو حبيت.

## نشر إصدار جديد
1. زوّد `version` في `salli_app/pubspec.yaml` (مثلاً `1.0.2+3`، الرقم بعد `+` لازم يزيد).
2. ابني الـ APK **بنفس مفتاح التوقيع** علشان التحديث يتثبّت فوق القديم. من غير توقيع خاص فلاتر بيستخدم مفتاح تجريبي مرتبط بجهازك، فأي تحديث من جهاز تاني مش هيتثبّت فوق. التوقيع الصح: <https://docs.flutter.dev/deployment/android#sign-the-app> (واحتفظ بنسخة من المفتاح ولا ترفعه).
3. من Releases: Create a new release ← ارفع الـ APK باسم `salli-ala-muhammad.apk`. غيّر رقم الإصدار في `kAppLink` (أو استخدم `releases/latest/download/`).

## ملاحظات تشغيل
- التنبيه الدوري بيستخدم `setAlarmClock` علشان يتخطى Doze وتوفير الطاقة، فبتظهر أيقونة منبه صغيرة في شريط الحالة.
- على شاومي/سامسونج/أوبو: فعّل «التشغيل التلقائي» واجعل البطارية «بدون قيود» لو التنبيه اتأخر.
- التنبيه الفايت (لو الجهاز كان مقفول وقتها) مش بيتعوّض، والجاي بيرجع بعد التشغيل (بعد أول فتح قفل).
- `USE_EXACT_ALARM` مناسب للتوزيع بـ APK، لو هتنشر على Google Play شيله.
